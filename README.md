# 🖼️ Image Editor

A simple browser-based **Image Editor** built using **HTML, CSS, and JavaScript**.
The project allows users to upload an image, apply different filters and presets, reset the changes, and download the edited image.

## 🚀 Features

* 🖼️ Upload images from your device
* ☀️ Adjust **Brightness**
* 🌓 Adjust **Contrast**
* 🌈 Adjust **Saturation**
* 🎨 Adjust **Hue Rotation**
* 🌫️ Apply **Blur**
* ⚫ Apply **Grayscale**
* 🎭 Apply predefined filter presets
* 🔄 Reset all changes
* 💾 Download the edited image
* 📱 Responsive interface

## ⚙️ How It Works

1. Click **Choose Image** to upload an image.
2. Adjust the available image controls.
3. Experiment with different filter presets.
4. Use **Reset** to restore the original image settings.
5. Click **Download** to save the edited image.

## 🎛️ Editing Controls

| Control      | Purpose                                              |
| ------------ | ---------------------------------------------------- |
| Brightness   | Makes the image lighter or darker                    |
| Contrast     | Controls the difference between light and dark areas |
| Saturation   | Controls the intensity of colors                     |
| Hue Rotation | Changes the colors of the image                      |
| Blur         | Adds a blur effect                                   |
| Grayscale    | Converts the image toward black and white            |
